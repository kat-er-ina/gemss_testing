# Testing GEMSS on real-world datasets

## GEMSS Explorer App

To test GEMSS on real-world datasets, use the [GEMSS Explorer application](https://github.com/kat-er-ina/gemss/tree/main/app).

## Available Datasets

Real-world datasets are provided in the `data/` directory:
- **Metabolomics**: MetaboLights datasets (MTBLS1, MTBLS2, MTBLS8, MTBLS12968) - preprocessed
- **Colonoscopy**: Additional medical dataset - raw

To acquire new datasets from MetaboLights, see [`notebooks/get_data_from_metabolights.ipynb`](notebooks/get_data_from_metabolights.ipynb).
